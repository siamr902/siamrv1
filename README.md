<h2>Stack</h2>  

This is the first iteration of my portfolio website, and it built using `NextJS`. `Framer Motion` was used to create the animations, and `tailwindcss` was used for general-purpose styling. [React three fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction) helped create the floating orb in the hero section. If you're familiar with `three.js`, you'll find it easy to transition to `react-three-fiber`.
